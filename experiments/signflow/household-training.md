# Адаптация SignFlow‑R для раздела «Дом и быт»

Модель SignFlow‑R вычисляет 267 оценок в ONNX Runtime. Для бытового списка обучается линейный классификатор поверх этих оценок. Базовые веса зафиксированы. Дополнительный класс содержит записи других жестов. В приложении победа этого класса или оценка ниже 0,60 помечает лучший известный вариант как предположение. В таблице оценки обучения такие случаи считаются отклонёнными.

Каталог показа содержит 50 карточек. Из них в открытой разметке Slovo есть записи для «Комната», «Жарить», «Собака», «Аккуратный», «Комар» и «Красивый». Примеры обучения и проверки разделены по исполнителям. Список записей приведён в `household-samples.tsv`. [Набор Slovo](https://www.kaggle.com/datasets/kapitanov/slovo)

## Воспроизведение обучения

1. Возьмите обрезанные записи Slovo из `slovo/train` и `slovo/test` по идентификаторам из `household-samples.tsv` и найдите исполнителей в таблице аннотаций.
2. Подготовьте тензоры через `control.py --save-tensor` с манифестом для базовой модели. Для пакетного прогона создайте TSV без заголовка. В каждой строке укажите метку, ID записи, путь к тензору, раздел `train` или `test` и ID исполнителя.
3. Снимите оценки и обучите классификатор. Для обучения нужен NumPy.

```sh
model=experiments/signflow/legacy/SignFlow-R.onnx
java -cp /path/to/onnxruntime.jar experiments/signflow/OnnxProbe.java \
  "$model" /path/to/tensors.tsv 1,1,3,32,224,224 --batch > /tmp/household-scores.tsv
python3 experiments/signflow/train_household_head.py /tmp/household-scores.tsv \
  --model "$model" --output /tmp/household-classifier.json
```

Порог и стратегия обучения заданы до оценки на тестовой выборке. Проверка отражает работу на размеченных записях Slovo и не измеряет точность на видеопотоке телефона.
