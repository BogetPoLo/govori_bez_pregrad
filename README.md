# Говори без преград

Android-приложение для короткого общения на русском жестовом языке (РЖЯ). В приложении 25 повседневных жестов.

- **РЖЯ → текст.** Покажите один жест в камеру. Модель Slovo выбирает слово с наивысшей оценкой среди 25 вариантов. Кнопка «Посмотреть жест» открывает видео для этого слова.
- **Русский текст → РЖЯ.** Найдите слово в видеословаре и посмотрите, как показать соответствующий жест. Уроки загружаются с [SignFlow](https://signflow.ru/).

## Запуск

Откройте корневую папку в Android Studio, установите Android SDK с API 37 и запустите модуль `app`. Для установки приложения нужен Android 8.0 или новее. Из командной строки APK можно собрать через Gradle Wrapper.

```sh
./gradlew :app:assembleDebug
```

При первом открытии экрана распознавания приложение скачивает [модель `mvit32-2.onnx`](https://github.com/hukenovs/slovo). После загрузки жесты распознаются на устройстве. Для просмотра онлайн-уроков нужно подключение к интернету.
