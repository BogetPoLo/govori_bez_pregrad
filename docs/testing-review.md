# Проверка SignFlow

- Камера привязывает Preview и ImageAnalysis к жизненному циклу. Анализ оставляет свежий кадр, а ImageProxy закрывается в finally. Инференс использует ONNX Runtime вне UI-потока.
- Две инструментальные проверки сравнивают метку и оценки Slovo на одинаковом входном тензоре. Ещё 50 сценариев проверяют распознанное слово и ссылку на урок на двух записях для каждого слова каталога. Без контрольных данных эти проверки пропускаются.
- Приложение использует Compose и Android View для камеры и плеера. Локальные тесты JUnit проверяют обрезку записи, буфер длинной записи и выбор слова с наивысшей оценкой в каталоге.
- На устройстве проверьте разрешение камеры, остановку захвата при смене вкладки и повтор. В видеословаре проверьте окно SignFlow, переход в браузер и управление после ошибки сети. Проверьте, что результат распознавания открывает карточку того же слова.

Для контрольных данных и команды инструментального прогона см. [контрольный прогон](../experiments/signflow/README.md).
